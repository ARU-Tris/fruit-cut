## 실제 브라우저 조작

별도 개발 소스가 아닌 **생성된 `Fruit Cut.html`**을 로컬 HTTP 서버로 제공해 검증했습니다.

- 마우스 드래그의 시작점과 끝점 사이 직선으로 즉시 절단, 단면 노출, 낙하와 새 과일 진입 확인.
- 모아 베기 버튼을 켜고 10개의 선을 누적. 이때 과일 1개 유지, 물리 조각 0개.
- Ctrl+Z로 10개에서 9개로 감소, 선을 다시 추가하여 10개 복원.
- 한 번에 절단하여 **40개 조각** 생성 및 도마에 쌓임. 다음 과일 등장 뒤에도 40개 유지.
- 수박에 선 3개를 누적한 채 C로 청소: **조각 40 → 0**, 누적 선 3개와 활성 수박 보존.
- Esc로 누적 선 취소 확인.
- 아보카도·수박·오렌지·키위·레몬 선택, 절단, 과일 간 기존 조각 보존. 최종 혼합 조각 17개 유지.
- Space 슬로 모션 켜기·끄기, 음소거 켜기·끄기, 도움말, 그래픽 품질과 효과 강도 설정 전환 확인.
- 최종 실행본 브라우저 콘솔의 경고·오류: 0건.

## 검증 범위

- 브라우저 도구 정책이 `file://` 열기를 허용하지 않아 **파일 더블클릭 실행 자체는 자동 검증하지 못했습니다.** 같은 단일 HTML의 HTTP 실행과 외부 자산 없는 패키지 구조를 검증했습니다.
- 물리 Shift 키를 여러 드래그 동안 유지하는 입력은 도구에서 재현하지 못했습니다. Shift 이벤트 처리를 구현했고, 누적·동시 절단 모델은 자동 검사, 동일 기능의 모아 베기 버튼은 실제 브라우저로 확인했습니다.
- 소리 버튼 상태는 확인했습니다. 사람이 듣는 음질, 직접 조작하는 손맛, 기기별 FPS는 측정하지 않았습니다.
- 실제 사진 캡처와 동일한 포토리얼 질감이라고 주장하지 않습니다. 참고 이미지를 게임 텍스처로 복사하지 않고 3D 형상·질감을 절차적으로 만들었습니다.
